## 라우팅 ADR 개정 이력

| 버전 | 상태 | 비고 |
|---|---|---|
| v1.0 | Superseded | 리뷰에서 C1–C15 제기. 구현 기준 문서로 사용하지 않음 |
| v2.0 | Superseded | C1–C15 반영. 리뷰에서 N1–N11 제기 |
| **v2.1** | **Accepted** | N1–N11 반영. 이 레포의 `0001-tomverse-routing-v2.1.md` |

v1.0과 v2.0의 원본 PDF는 레포에 포함하지 않습니다. 두 버전에서 제기되어 해소된 항목은
v2.1 문서 §0의 변경 요약 표에 보존되어 있습니다.

v2.1 리뷰에서 나온 R1–R6은 문서 개정이 아니라 구현 시점 결정 항목으로 분류되어
v2.1 문서 **부록 A**에 기록되어 있습니다.
